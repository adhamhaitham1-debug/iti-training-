
=======================================================
Assignment 4 – Customize Your Linux Terminal
=======================================================

Implementation Notes:
- Requirement 1: Added alias print_content='ls -la' to list all files, including hidden ones, in long listing format.
- Requirement 2: Added alias go_to='cd' to allow seamless directory navigation with arguments.
- Requirement 3: Added alias search='grep --color=auto' to display matching keyword lines with color highlighting.
- Requirement 4: Added alias show_file='cat -n' to print file contents alongside line numbers.

All configurations were appended to ~/.bashrc to guarantee persistence across all future terminal sessions.
