Assignment 4 – Customize Your Linux Terminal Report
=======================================================

Command Implementation Details:
--------------------------------
1. print_content  -> alias print_content='ls -la'
   Displays detailed file listings including hidden files.
2. go_to          -> alias go_to='cd'
   Navigates directly to the specified target directory.
3. search         -> alias search='grep --color=auto'
   Searches for matching strings in files with color highlighting.
4. show_file      -> alias show_file='cat -n'
   Outputs file text prefixed with line numbers.
5. remove         -> alias remove='rm -i'
   Prompts interactive confirmation (y/n) before removing files.
6. make_dir       -> alias make_dir='mkdir -p'
   Creates full directory trees including missing parents.
7. create_file    -> alias create_file='touch'
   Creates a new empty file.

Persistence:
All custom aliases were appended to ~/.bashrc to guarantee persistence across all terminal sessions.
